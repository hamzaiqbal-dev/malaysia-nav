## Checked and fine

- Legal notices: `LICENSE` and `NOTICE` are untouched in both chains. The map shows "© OpenStreetMap contributors"; About has the OSM credit, "Open-source licences" (which names Organic Maps and Apache-2.0), privacy and terms.
- Map downloads: `METASERVER_URL` is empty and the only server is `https://github.com/hamzaiqbal-dev/malaysia-nav/releases/download/`; a unit test guards this. No request goes to Organic Maps' servers. The other host the app can contact is openstreetmap.org (login and editing, only if the user chooses).
- No secrets, keystores, analytics or ads added. No new exported components. `com.sampai.maps` is applied to the provider authorities, so it cannot clash with an installed Organic Maps.
- Min SDK 21: the new Java uses `java.time`, records and streams, which are safe because core-library desugaring is on.
- Release build: R8/minify and resource shrinking are on; no signing keys in the repo.

## Before a public launch

1. Merge in the order above, then build once from `master` and test on a real phone: install, download the Malaysia map, search, route, drive with the HUD on and off, file a Lapor report, open About and every legal page, in Malay and English, light and dark.
2. Register Sampai's own OpenStreetMap OAuth app (finding 3) or hide OSM login.
3. Do the security PR (task 2c): HTTPS only, SECURITY.md, dependency CVE list.
4. Choose the support email, fill in the privacy policy contact, publish the policy at a public URL (Google Play requires one), and update the privacy text for GitHub hosting.
5. Lawyer review of `docs/my/LEGAL.md`, the privacy policy and the terms; trademark check for "Sampai".
6. Decide map hosting (GitHub Releases or an own server) and who replaces the bundled map files each month.
7. Release signing: create the upload keystore and keep it only as GitHub Actions secrets.
8. Malay voice guidance, and a native-speaker pass over the Malay strings.
